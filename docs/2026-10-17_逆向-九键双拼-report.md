# 九键双拼接入记录

分析日期：2026-10-17；报告类型：普通 APK 接口分析与功能接入（flavor = null）。

## 结果与使用

模块新增「键盘 → 输入方案 → 九键双拼」开关，默认关闭；「九键双拼方案」支持小鹤（默认）、自然码、微软、搜狗、智能 ABC、拼音加加、紫光。开启后重启输入法，选择小爱「拼音9键」使用。关闭模块开关会恢复小爱原有双拼设置，因此小爱自身全局双拼开关仍可影响原生九键。

复用小爱原生九键数字输入、分词、候选与选词流程。模块仅在 T9 引擎初始化调用期间提供临时双拼配置，未写入小爱的设置文件；26 键、英文、形码和 18 键继续使用各自设置。当前设备均离线，原生解码效果、真实选词和手势尚待真机验收。
