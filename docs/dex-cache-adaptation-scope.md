# DEX 缓存适配范围

- auth：用户在审查发现五类遗漏后明确要求“都给我适配上去”，授权修改本项目并验证这些适配。
- in_scope：符号缓存失效与校验、临时异常重试、剪贴板动态加载缓存、独立键盘选择、形码、18 键、字母下滑快捷操作及适配状态。
- samples：项目已有的五份超级小爱输入法 APK、五份剪贴板 APK；从 0.2.1053 解包资料生成的独立重命名测试 DEX。
- device：当前已授权的 ADB 设备，仅在临时目录运行独立探针。
- network_profile：本地源码、离线 APK、ADB；只读 GitHub Release 记录用于确定版本基准。没有扫描第三方服务。
- delivery：代码、测试、构建产物和报告。没有安装替换宿主、修改输入法设置或发布 Release。

正式版本基准为 GitHub Release `11-2.1.6`；已有工作树修订 `2.1.6.4`，本次对外版本为 `2.1.6.5`，内部构建号为 `19`。
