# 2.1.6.5 DEX 缓存适配完整日志

本次提交补齐此前审查发现的五类遗漏，包含代码、回归测试、验证脚本、接口参考资料和技术报告。版本为 `2.1.6.5`，内部构建号为 `19`；正式版本基准保持 `11-2.1.6`。提交前本地 `main` 与远端 `origin/main` 均位于 `4beb50b`。

## 变更日志

1. **缓存标识覆盖完整 ZIP 目录。** 新增 `ApkFingerprint`，对所有条目的名称、CRC、大小、压缩大小和压缩方式计算 SHA-256，解决仅取 APK 尾部 64 KiB 时可能漏掉 DEX 变化的问题。模块构建标识、缓存结构版本、APK 大小和时间戳继续参与缓存键。
2. **命中校验与失效重扫。** 校验必需键覆盖、成功与失败集合互斥、描述符可加载性、列表数量、类型、成员归属、静态属性、参数和返回值。异常缓存自动重扫，后续真实成员解析失败会使磁盘缓存失效；调用错误类型的读取接口不会误删有效缓存。
3. **临时异常重试与完整写入。** 仅将明确的 `FingerprintMiss` 保存为稳定未命中；类加载、JNI 等临时异常不写入长期负缓存。批量结果在数量检查通过后发布，文件通过同目录唯一临时文件原子替换。
4. **动态剪贴板缓存。** 从定义目标类的 DexFile 定位真实 APK，向类加载监听路径传递当前进程缓存目录；后续获得完整 Context 时补充缓存信息。安装集合分别防止类加载重入、重复 Hook 和缓存初始化遗漏。
5. **新增七组键盘接口指纹。** 引擎、布局、动作、选择面板、设置、下滑手势和字母外观共用 `KeyboardAbi`。参考资料包含 178 个接口符号和 129 个结构见证，以字符串、参数结构、操作码及调用/字段引用定位实际成员，并兼容 `const-string/jumbo` 的字符串池变化。
6. **接入所有新增键盘路径。** 独立键盘选择、形码、18 键、原生键盘快捷操作、下滑绘制和排版改用解析结果，移除相关路径的固定 21053 版本门槛与宿主混淆名依赖。代理按解析后的方法身份分发；匹配失败时跳过对应功能并保留原生路径。
7. **适配状态完整上报。** 七组新接口及 Hook 安装失败纳入状态，首页检查剪贴板报告的版本和模块构建标识，缺少有效报告时显示等待状态，成功文案与功能开关保持一致。
8. **验证与维护工具。** 新增缓存回归测试、参考资料生成脚本和整体重命名验证脚本；设备探针检查缓存来源、七个桥接对象以及动态 APK 来源。桌面替身测试显式注入参考映射，生产路径仍要求成功解析。补充 `org.json` 测试依赖、剪贴板包可见性和 Python 缓存忽略规则。
9. **文档和版本。** 更新 README、适配范围和技术报告，版本由工作树 `2.1.6.4 / 18` 更新为 `2.1.6.5 / 19`，保留正式版本三段。
